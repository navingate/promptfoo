> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Freeze a fresh 36-case native defense candidate whose authorization decisions require a model-visible registry route/time join, without a live model call.

**Architecture:** Start from the frozen v7 detector, scorer, and transport. Regenerate each v6 native capture from its original session, insert one neutral near-match registry row before consent, and assert its native grant and continuation match v6. Give every surviving grant four visible registry rows. A fresh v8 grid and manifest bind the changed producer, independent reference, counterfactuals, and no-oracle controls.

**Tech Stack:** Node.js 22, ECMAScript modules, Node test runner, existing F4 benchmark helpers.
