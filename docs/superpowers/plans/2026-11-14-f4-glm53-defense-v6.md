# F4 GLM-5.3 Defense v6 Candidate Implementation Plan

> **For agentic workers:** Use the test-first workflow. Keep the scored v3 sources and artifacts unchanged.

**Goal:** Build an offline, enterprise-credible native defense candidate that adds validity-time and selector-mismatch unauthorized survivors while preserving an independently decidable authorization join.

**Architecture:** A new v6 producer selects the v5 thirteen-capture cohort, changes the covering registry entries for two formerly authorized survivors before consent and remediation, and records their native v3 unauthorized-survivor continuation. The remaining authorized survivors retain the v4 continuation. A new generator writes fresh-seed capture and evaluator files. A v6 runner reuses the existing captured-defense session, parser, and scorer without changing output format.

**Tech stack:** Node.js ESM, Node test runner, existing F4 estate and capture helpers.
