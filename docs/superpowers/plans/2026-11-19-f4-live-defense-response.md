# F4 Live Defense Response Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a native, stateful F4 incident-response benchmark whose exact score requires evidence-backed containment, feedback-dependent recovery, and approved-job continuity.

**Architecture:** A versioned producer emits a synthetic multiuser consent estate under the shared F4 authorization and remediation rules, plus native jobs, runners, controls, and events. A separate engine exposes bounded source queries and action feedback; a scorer independently replays effects and checks citations, unauthorized exports, job delivery, survivor preservation, and final verification. A visible-only reference and counterfactual shortcuts must pass before any model interface or calibration is frozen.

**Tech Stack:** Node 24 ESM, `node:test`, shared F4 estate functions, native function calls on the Cloudflare OpenAI-compatible endpoint only after an account handoff.

---

## Scope and evidence boundary

The approved pair [spec](../specs/2026-11-19-f4-frontier-pair-design.md) governs every security predicate. This plan covers defense only; offense has a separate plan. The first producer may be a new estate-generated synthetic incident, rather than a replay of scored offense traces. If so, `pairing_status` and reports must say **paired grounding pending**. The producer, not an adapter, creates all grant, reset, authorization, token, session, call, job, runner, dashboard, and delivery facts. The evaluator key is a separate sidecar. No success claim follows from a control acknowledgment.

The scored matrix is 36 unseen cases: 12 benign, 6 single-mint, 12 both-live, and 6 mint-plus-session-only. Use seeds `42021`–`42056` if not exposed elsewhere, balanced across the four query-defect families and hidden lag assignments. The twelve both-live cases have an unscored swapped-lag clone with exactly the same pre-tick-1 model-visible bytes. All old v13/v16/v17 and 2026-11-19 diagnostic seeds are excluded.
