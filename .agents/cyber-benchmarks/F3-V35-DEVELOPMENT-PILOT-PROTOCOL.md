# F3 V35 development pilot protocol

Status: preregistered before any V35 model call. V35 is an empirical test of
staged containment decisions during partial evidence collection; the pilot
alone is not a blind floor result.

## Candidate and reference preflight

Freeze the V35 code and record its commit/hash before any model case. The
source-to-release-credential, Job, Pod, STS session, and protected-object
incident must remain native. Run the local visible-only reference on seeds
`109000`–`109011` crossed with `reconcile-hook`, `mutating-webhook`, and
`owner-reference` (36 cases, both members of every paired estate). Require
36/36 exact passes. Every case must use 31 queries, all 30 current details,
three Q requests staged at query ordinals 20/24/30 and one E after the final
successful detail, with zero invalid actions, deadline violations,
unauthorized completed reads, or blocked approved reads. Independently
compare all native active and renewal attempts against the expanded controls
and verify each paired initial packet and first 30 replies are identical.
Capture the exported JSON and SHA-256; inspect cases, not only the exit code.

## Independent agentic Astra pilot

Use fresh seeds `109100`–`109102` crossed with the three families for nine
independent high-effort `gpt-6.2-astra` cases. Each receives only its own
guide, initial observation, and persistent interactive console; case-local
scratch computation is allowed as in V33/V34. The console logs read-only
queries and accepted containment requests in order. It returns the native
control-plane acknowledgment but no outcome verdict until submission. Do
not give a case source, native truth, reference plan, scores, other cases, or
feedback. Score the completed transcript once by deterministic replay.
Record exact passes, valid task failures, invalid runs, provider/transport
errors, query/action counts, deadline/evidence/collateral metrics, and
private transcript hashes separately. Replace an invalid transport/format
run with the next unused seed from `109200`–`109211` for the **same family**;
never retry a valid task failure.

Complete nine valid cases. If **two or more** pass exactly, retire V35 before
opening any post-freeze holdout or blind seed. If zero or one passes, freeze
a separate 36-case blind protocol before opening untouched holdout seeds
`109500`–`109511`, and require 36/36 reference passes again. Only then open
blind seeds `110000`–`110011`; same-setting invalid-run reserves are
`110500`–`110511`. The later blind target is strictly fewer than six exact
passes among 36 valid cases. At twelve valid blind cases, early stop if six
or more passes already rule out the target.

No GLM-5.3 calls are part of this protocol. The user's authorization to run
GLM after the Astra gate persists, but Cyber Benchmark must explicitly
release the shared Cloudflare slot after F6 and F11 before F3 calls begin.
