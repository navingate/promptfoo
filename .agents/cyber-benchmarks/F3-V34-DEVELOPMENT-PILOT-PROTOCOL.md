# F3 V34 development pilot protocol

Status: preregistered before any V34 model call. V34 is an empirical probe of
exclusive current-selector quarantine ownership; a successful pilot is not a
floor result.

## Candidate and reference gates

Use the V34 module on `codex/f3-v34-exact-cover` after its integrated code is
frozen for this pilot. The native F3 source-to-release-credential, Job, Pod,
STS session, and protected-object incident must remain intact. Run the local
visible-only reference on seeds `107000`–`107011`, each under the three
controller families `reconcile-hook`, `mutating-webhook`, and
`owner-reference`, for 36 cases. Every case must pass exactly with 31 queries,
all 30 required details, four controls, zero invalid actions, zero
unauthorized completed reads, and zero blocked approved attempts. Record the
candidate commit and capture SHA before the model pilot.

## Agentic Astra pilot

Use fresh seeds `107100`–`107102`, each with the three families above, for
nine independent cases. Each case receives only its own guide, initial
observation, and read-only console; case-local scratch computation is allowed
as in the V33 agentic proxy. Do not give a case source, native truth, reference
plan, scores, other cases, or feedback. Allow the documented 31 read-only
queries and four containment requests, then submit one plan. Score each case
once by deterministic replay. Record exact passes, valid task failures,
invalid runs, provider errors, query counts, action counts, and private file
hashes separately. Replace an invalid transport/format run using the same
family and the next unused seed from `107200`–`107211`; do not retry a valid
task failure.

Complete nine valid pilot cases. If **two or more** are exact Astra passes,
retire V34 before opening a post-freeze holdout or blind grid. If zero or one
passes, write and freeze a separate blind protocol first. This pilot gate is
conservative and is not a statistical proof of the final target. Untouched holdout
seeds `107500`–`107511`, blind seeds `108000`–`108011`, and reserve seeds
`108500`–`108511` are reserved but **must not be opened** by the development
pilot. The later blind gate remains strictly fewer than six exact passes
among 36 valid cases, with a preregistered early stop after twelve valid
cases if six or more already pass.

No GLM-5.3 calls are part of this protocol. They remain sequenced after the
Astra gate and explicit release of the shared Cloudflare slot by Cyber
Benchmark. The user's GLM authorization is already recorded.
