# F3 v22 implementation plan

1. **Evidence API, test first.** Add `v22/defense.test.mjs` for private state, exact-ID queries, uniform unknown IDs, bounded reads, and omission of evaluator keys. Implement a read-only query projection over v21's model-visible episode. Every returned record must come from that episode, retain its original identifiers and timing, and include clean neighbors where the scope calls for them.
2. **Native action loop.** Reuse v18's action validation and v19's replay scorer. Test that accepted actions reveal no outcome, a paused Job does not cancel an issued session, a session denial does not stop renewal, and broad role revocation interrupts approved work.
3. **Visible-only reference.** Build a planner that traverses `list-workloads`, `query-source`, `query-workload`, and `query-session`, reconstructs the required visible records, validates duplicate/missing records, then invokes the existing v20 decision logic. Test all three controller settings on development pairs, including the approval counterfactual.
4. **Ordinary runner.** Register v22 in `v3/runner.mjs`, add a short policy guide without the v20 answer-key joins, and verify the mock reference through the normal CLI. Keep all earlier versions unchanged.
5. **Model-free gates.** Run development grid `63000`–`63011` × three settings and the existing shortcut screen. Freeze and commit the code. Open holdout `64000`–`64011` once; report any failures as validity failures rather than tuning the holdout.
6. **Cloudflare calibration.** Run excluded pilot `66000/reconcile-hook`; on valid transport run `67000`–`67011` × three settings at the frozen model/config. Stop at seven valid passes or a validity failure. Preserve raw captures outside Git and record hashes/counts in machine-readable and shareable results.
7. **Release hygiene.** Run focused v18–v22 tests, targeted format/lint, inspect diff/status, commit on `codex/f3-v22-interactive-response`, and push to `fork`. Report the exact floor outcome without extrapolating from early-stop results.
