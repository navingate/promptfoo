# F3–F11 Construct-Quality Audit (18 planes)

**Scope:** read-only screen-vs-scorer audit of 9 cyber-benchmark families × {offense, defense}.
**Snapshot:** worktree `.worktrees/converge`, branch `codex/cyber-converge-wave23` @ **`ab6abc2a1`**. `git status --porcelain plugins/cyber/benchmarks` empty before AND after (re-checked; no sibling-agent drift).
**No model/API calls.** Every number is from importing the harness modules + the runner's own `renderMessages` (copied verbatim) in-process. Zero network — the rate limit was never touched. `model` = the glm-5 screen pass-rate in `baseline/` (secondary context, not the signal).

**Method (computed):**

- **Screen** = the runner's `render*` output for `calibrationInstance(spec)` — the exact SUT-visible prompt.
- **Disclosure gap**: ablate `calibrationReference` (drop/flip each field, re-score; flip-to-fail = rewarded) then check the screen text AND the bound `evidence/observation/prompt.txt` (F4/F6/F9) or `generate-evidence.mjs` (others). Tagged **WITHHELD** / **CONTRADICTED** / **UN-ACTIONABLE**.
- **Trivial shortcut**: for detection/incident planes, an **exhaustive single-visible-path separator scan** (every presence + equality predicate over the item/instance's visible scalars) + each harness's own single-field battery + bespoke flag/policy readers, scored by the real scorer on the **designed set** (the plane's `calibration/*-config.json`, or the actual screened set from `baseline/`). The scan was **validated on f8**: it independently rediscovers a perfect single-field split.
- **Label-leak**: the separator scan's perfect-separator finding + a token scan for evaluator fields / marker stems.
- **Confidence:** **(C)** executed offline on this snapshot; **(I)** inference (offense victim-loop behaviour needs a live model).
