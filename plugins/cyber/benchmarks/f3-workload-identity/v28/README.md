# F3 V28 expanded response window

V28 stages six release Jobs and six independently authorized scheduled Jobs in one synthetic enterprise response window. Each Job has an issued-session read and a pending renewal read. The 24 planned reads combine compromised release sources, current change and owner approvals, expiring grants, group-membership audit changes, and approved work that must continue. The correct even/odd plans use thirteen/fourteen controls within a fourteen-action budget. The crowded cohort and tight budget are deliberate artificial constraints; the source → release credential → Job → Pod → STS chain remains causal and query-visible.

See the [design](../../../../../docs/superpowers/specs/2026-11-20-f3-expanded-cohort-design.md) and [blind pilot protocol](../../../../../.agents/cyber-benchmarks/F3-V28-ASTRA-PILOT-PROTOCOL.md). This is a short-horizon simulation, not a live enterprise deployment.
