# F3 V30 budgeted SOC index

V30 preserves the V29 native workload-release and cloud-session incident but
adds thirty adjacent archive IDs to the first read-only SOC index. A completed
publication journal identifies which thirty credential, Job, and session IDs
have a planned observation inside the response horizon. The defender can make
only thirty-one queries: one index plus thirty detailed records. The archive
and strict evidence budget are artificial benchmark stressors; all records
needed for the exact containment plan remain visible and queryable.
