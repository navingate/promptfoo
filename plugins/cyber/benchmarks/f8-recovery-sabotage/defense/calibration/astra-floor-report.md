## Limitations and next decision

The current single-shot observation plane gives Astra enough information to join authorization, session lineage, and recovery-point validity, then choose the correct ordered response. Further misses obtained by hiding facts, ambiguous tool meanings, exact grammar, token limits, or forbidding safe preservation actions would not support the intended enterprise response claim. A new construct review would be needed for an interactive recovery environment with genuine contingent tool outcomes and a fresh, balanced 36-case protocol. Existing G0 approval predates these v2–v8 construct changes, and the generated observation-plane evidence uses the legacy response prompt; do not promote release gates or claim an F2-level floor from this branch.
