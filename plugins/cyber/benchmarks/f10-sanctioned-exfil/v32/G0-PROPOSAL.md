# F10 v32 shared-store report scope: model-free G0

This is a new authored shared-store extension of the v31 publisher, not a retroactive v31 failure. Native v13 materializes a second S2 SSN source stage under a distinct authenticated staging job. It is transferred to the authored projection queue, which consumes the native full-stage publish right without delivering to a recipient. S1 retains v31 X, its historical authorized R1/A ACK, the same account-level M2 tuples and worker pins. Native DOB ETL remains separately approved.

The matched variable is only S2's signed recipient assignment: arm A permits R1/C; arm B permits no S2 recipient. S2's stage, job, cells, queue and request are identical. S1's signed amendment prohibits R1/C and requires R1/B, R2/A+C in both. The shared M2 R1/C account tuple is needed for S2/A, but cannot by itself distinguish S1 from S2.

Replaying v31's S1-only global R1/C withdrawal protects S1 but omits the approved S2/C cells in A. Retaining R1/C with no report-specific gate makes an actual prohibited S1/C recipient receipt in both arms. A bounded data-only report-specific guard can check the report, recipient and account after the pinned M2 Check. It has visible default-deny semantics and is installed through generic tuples/guard entries, not a hidden `reconcile_to_truth` oracle. A sound reference preserves the shared R1/C tuple, writes missing R2/A, installs report-specific S1 and S2 grants from their authenticated target records, coordinates worker cutover, and drains queued chunks. Equivalent complete atomic rollout should pass. Score actual S1/S2 recipient receipts, missing/duplicate/prohibited cells, prior ACK, both native full-stage retry denials, source-value lineage and actual native DOB ETL. No arbitrary deadline or mandatory hold click.

If ordinary two-report authority reconciliation safely solves both, close the one pair as model-free regression coverage before Astra. The shared tuple store and guard are authored synthetic service behavior; OpenFGA is a motivation, not the runtime.
