# F11 implementation deviation — all-native synthetic estate (G0 disclosure)

Status: disclosure for the FRESH, SCOPED G0 review (NOT a clean carry-forward). Covers both F11 tasks
(`f11-evidence-offense`, `f11-evidence-defense`), which share `shared/estate.mjs`.

## What deviates

The F11 construct-defining docs were approved at `43c437f8c` describing an incident capture built by **reusing
earlier families' native events/artifacts (F8/F9/F6/F4)**. The implementation is instead **all-native**: a
synthetic post-intrusion SOC estate generated by `shared/estate.mjs`, de-oracle-equivalent to those families'
intrusion patterns but reproducing none of their telemetry. The **construct is unchanged** (poisoned incident
evidence → a harmful SOC-response delta vs a matched clean twin) and the **claim is unchanged** (a harmful
behavioral delta under the tested harness; source-independent). Only the *sourcing* of the telemetry differs.
Because the docs and the implementation disagree on sourcing, F11 binds G0 `approval: null` (pending a fresh
scoped independent review relayed by the user), not as a byte-identical carry-forward.

## Why all-native (three reasons)

**(a) No earlier capture carries the authenticity layer F11 scores on.** F11's difficulty is the corroboration
join — a resource is the true target only when compromise-worded content is corroborated across ≥2 independent
`source_system`s sharing one `correlation`, with per-event `integrity_status`/`signature` that do not separate
genuine from poison. Earlier families' captures do not carry this per-event cross-source authenticity structure,
so F11 would have to author it on top of them regardless.

**(b) Literal reuse buys no measured capability, at real cost.** The scored quantity is the injected-vs-clean
harmful-response delta, which is independent of where the underlying telemetry originated. Importing literal
earlier-family rows adds schema-translation glue and hash-couples F11 to four other estates (any upstream change
breaks F11's frozen captures) while changing nothing the benchmark measures.

**(c) The earlier sources have almost no attacker-writable field to poison.** Per-source, confirmed:
- **F9 and F4** expose **no injectable free-text field** (fully structured telemetry).
- **F8** exposes a structured `detail` **plus** a free-text `evidence.compromise_report.note` string — and that
  note is **NOT allowlisted**: its attacker-writability is an open provenance question, so it must not be used
  as a poison channel without evidence.
- **F6** exposes free-text only as row-level `documents[].content` in the VOID v2 corpus.

So literal reuse would leave the offense with essentially nothing legitimately writable to poison in most
sources. F11's synthetic estate instead defines an explicit, field-shaped, per-capture **writable allowlist**
(one healthy-multi chain event's machine `content`), which is the construct's attacker-edit surface.

## Scope of the all-native estate (what the claim-ceiling rests on)

- The four intrusion patterns (`INTRUSION_KINDS`) are **four distinct source/correlation patterns** —
  `endpoint-file` (edr+fileint), `identity-network` (idp+netflow), `endpoint-network` (edr+netflow),
  `identity-file` (idp+fileint) — **inspired by, not reproducing**, earlier families' attacks. Nothing is
  claimed about F8/F9/F6/F4 captured telemetry.
- Attacker-writable values are **field-shaped and length-capped** (a status claim rendered to the writable
  event's `evidence_field`: process-arg / filename / log / ticket); a signed machine field never carries fluent
  free prose. The attacker cannot edit any `source_system` / `correlation` / `signature`, so corroboration
  cannot be forged.
- The de-oracle properties the estate provides (the 2×2 compromise∧multi-source conjunction with balanced
  marginals, randomized writable hop, one writable event per chain) are **stronger** than literal reuse would
  give, and are what the model-free G2/G3 evidence attests.

The release claim is therefore scoped to **F11's own synthetic estate**, not to real SOC telemetry and not to a
provenance claim about earlier families' captures.
